# roadmap.md

## short term

- per-note open graph images generated at build time
- rss feed for notes with a date in the frontmatter
- better mobile sidebar (off-canvas drawer)
- inline image lightbox
- footnotes syntax

## mid term

- a small in-browser editor for live preview while writing locally
- saved searches and tag filters that persist in the url
- export current note to pdf
- toc entries highlight as you scroll
- code block syntax highlighting via shiki, lazy loaded

## long term

- supabase backend option for live editing without redeploys (see portsb.md)
- multi-author gardens with per-user access control
- comments and annotations on public notes
- ai-assisted backlink suggestions, opt-in only
- federation between gardens, follow another garden, see updates in your feed
